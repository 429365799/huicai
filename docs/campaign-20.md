## 设计节奏

沿现有「石罅初泉 → 苔盏 → 小溪 → 河湾 → 潮岸 → 大海」的 20 个场景前进。每四关一章，直接使用现有 Theme 的背景和色调，不新增背景动画。关卡标题是这一程的动作，场景标题是落笔所在的地方。

| 章 / 关号 | 教给玩家的思路 | 组合与收束 |
| --- | --- | --- |
| 泉醒 / 0—3 | 初染、相映、汇色、聚流；看见四向连通，找能同时接入多片的起点 | 3 步小题起步，第 3 关用 4 步考起点选择 |
| 涧行 / 4—7 | 借色、回环、渡色、回澜；已用过的颜色还能再用 | 从 4 步回色桥到 5 步连续扩张 |
| 河声 / 8—11 | 砚痕、疏径、曲岸、绕石；分散砚石阻断近路 | 绕行叠加回色，第 11 关展开到 10×10 |
| 潮生 / 12—15 | 遥应、牵光、共鸣、双生；两端同色才接通 | 小棋盘学传色，再叠加砚石与回色 |
| 入海 / 16—19 | 落笔、相承、合潮、归海；在远处铺垫后再汇合 | 先换区，再分别叠加绕石、传色，终关五种思路共同收束 |

这是章内逐渐收紧、换章时稍作缓冲的曲线，不要求每一关的指标严格高于上一关。每逢新思路先回到 6×6，减少阅读负担；之后增加规划深度。后期仍以五步为上限，不靠加颜色和大量碎块延长操作。

聚流、回色、铺垫是基础染色规则下的不同解题思路；砚石、双生是改变连接关系的棋盘机制。没有为凑五种机制新增额外特殊格。

约束：

- 始终只有四色，四向物理连通；传色点不用于掩盖断开的碎岛。
- 每个新题最多两片单格色域；不是逐格点掉杂色。
- 砚石最多四个，实际最高占比约 4.69%，既不边接也不角接。
- 1—15 关都保存一条固定落笔点、每步扩大连片面积的最短解。
- 16—19 关保留汇流目标，但必须在过程中切换到尚未连上的区域。
- 20 个棋盘去掉配色、旋转、镜像差异后仍不重复。
- 题面固定，五种染色动效每连续 5 关切换一次，25 关后循环；重试不改变题目和所属动效。

## 机制为什么不是装饰

由真实游戏 Core 求解器枚举任意区域、任意合法颜色，不把预设答案当作唯一允许的玩法。

- 回色关：所有不重复使用颜料的操作序列都不能在预算内完成，包括换区落笔的序列。五步关在四色条件下也必然重复用色。
- 砚石关：取下砚石，恢复生成时石下的原色后，至少能少走一步。这是明确的对照题，不代表把砚石改成任意颜色都会变简单。
- 传色关：取消传色边，原步数预算内无解；一对标记确实参与解题。
- 铺垫关：穷举所有固定落笔区域及所有允许颜色序列，均不能在预算内完成。
- 第 19 关同时通过上述三种棋盘/策略对照，并在五步内完成。它有三个可行开局，不声称唯一解。

第 0 关仍用历史题，入门后的相映提供五种可行开局。章末聚流、双生分别只有一种可行开局，作为集中观察的试炼；可以撤销，也可在浏览器设计预览中使用提示。广告规则没有调整。

## 离线复现与调参

`node tools/generate-campaign.js` 按固定规格搜索候选并输出 JSON Lines；指定末尾数字只生成对应关。不会自动覆盖题库。选中的种子、生成参数、题面、最短解、扩张解、石下对照题保存在 `campaign-evidence.json`，手机包不包含该文档或出题工具。

`tests/challenges.test.js` 从记录的种子重建棋盘，并重新求解与做机制对照。修改题面、目标色、步数、传色点后必须重新验证。调整难度优先改可行开局范围和色域连接；不要只加步数、加石块或缩小色块。

## 剧透答案

### 1 相映

一滴水落进苔盏，两片颜色第一次相映。

同色相接。四向相邻的同色块会一起染色。换一种颜色，接上身旁的另一片。

2. 第 1 行第 3 列 → 蜜柚
3. 第 1 行第 3 列 → 珊瑚

### 2 汇色

水珠越过滴石，散开的水色汇向一处。

一笔汇流。留意能同时接上几片颜色的位置。连成的大色块，还能继续换色。

1. 第 1 行第 3 列 → 晴蓝
2. 第 1 行第 3 列 → 珊瑚
3. 第 1 行第 3 列 → 蜜柚
4. 第 1 行第 3 列 → 青芽

### 3 聚流
