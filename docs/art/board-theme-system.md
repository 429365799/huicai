# 洄彩画板与背景主题

当前主入口回归纯画板玩法。旧连续长卷、叶子跟镜和局部复色实验不再由 `story-preview.html` 加载；该入口直接展示共享游戏画板。

视觉层级：

1. 四色棋盘是最高对比、最高饱和层，负责全部玩法判断。
2. 深墨漆木与旧金双层边框定义“待修复画作”，四角金钉帮助完整识别棋盘边界。
3. 背景只使用低饱和水墨色和稀疏线稿，不复用四色颜料作为信号色。

染色反馈：点击格是唯一扩散原点；传播按上、下、左、右四向广度优先递归，同一深度的相邻格近乎同时开始。每格内部从接触前一格的边缘生成一层柔边主墨迹和三枚确定性小晕点，最后自然铺满。没有跨越棋盘的全局圆环；单次总时长不超过 1600ms，动画期间锁定再次落笔。逐级音符按同一传播层级播放。

20 关按五幕组织，每幕四景：

- 泉醒：石罅初泉、苔盏、滴石、浅漪
- 涧行：芦岸、萤汀、雨渡、荷影
- 河声：山溪、石桥、竹湾、归舟
- 潮生：潮痕、风礁、海门、星湾
- 入海：远帆、月潮、曙海、万色归流

`src/theme.js` 保存固定映射，游戏按公开关号取景。当前只有 0–5 共六个可玩关卡；余下主题已经定义，但必须等对应关卡内容接入后才能在正常关卡条中体验。
