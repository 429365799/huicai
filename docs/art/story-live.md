# 唤泉 + 第 0 关：常驻故事样例

入口：story-preview.html。仅浏览器体验验证，未迁移到 wx/tt 渲染器。

## 层次

- 底层：原有无叶水面及透明小叶，保持背景存在，不再擦除插画。竖屏裁切两侧，保持插画纵横比，无拉伸。
- 中层：透明 iframe + 透明 Canvas；棋盘纸面 alpha 0.72，头部 0.84，操作区 0.86。
- 色块：使用原有不透明色值，未对 Canvas 整体设置透明度；故事模式关闭染色缩放弹跳。
- 常驻动效：一条虚线水流、一圈循环淡涟漪；无镜头持续摇动。减少动态模式停用循环。

## 行为

- 开始：背景不变，只隐藏封面文字并显现游戏 UI。
- 有效染色：受信的同源 iframe 发送 paint 事件，水流短时加强；无效点击不触发。
- 染色动画结束且胜利：won 事件驱动叶片沿出口从 87% 前进到 94%，约 2.2 秒，随后显示轻提示。不开启原有大彩带，不覆盖整个背景。
- 重试 / 撤销：reset 事件复位叶片；回到画卷保留当前解题状态，再进入可继续。
- 样例只开放第 0 关，原浏览器预览及原生默认路径仍保持原来的六关表现。

## 验证

- 新增 story-live.test.js，覆盖 390×844 / 375×667 / 320×568：透明清屏、隐藏选关不可触发、三次 paint、一次 won、无彩带、重试复位。测试通过。
- 原 npm test 回归通过。
- 浏览器实看棋盘与泉水同屏，手动完成前两笔时剩余步数 1，叶片仍停在水道下方。
- 浏览器手动第三笔完成，棋盘全蓝，轻提示出现，小叶已向出水口下游移动；回到画卷按钮改置右下，避免遮住终点。
- 未验证：微信/抖音真机适配、最低端机性能、全部机型安全区、主观透明度与动效节奏。循环水纹是图形叠加，不是流体模拟。
