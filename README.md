# 洄彩

一个使用原生 JavaScript 与 Canvas 2D 编写的通用小游戏项目。共享源码不直接依赖 `wx` 或 `tt`，只在构建时注入微信小游戏或抖音小游戏运行时并生成对应平台工程。

## 当前玩法

- 四方向连通块染色，限定步数内统一为目标颜色
- 第 0 关「初染」：原版 6×6 四角留白、32 个彩格的三步入门题，无障碍、无传色点
- 共 20 关（0—19，含初染），按泉醒、涧行、河声、潮生、入海五章递进；每四关引入一种思路，最短解均为 3—5 步
- 顶部关卡条支持横向拖动，浏览器也支持滚轮/触控板；固定按钮宽度，不随关卡数量缩小，切关/进入下一关时自动露出所选项
- 棋盘从 6×6 过渡到 8×8，章末与终章有 10×10；砚石最多 4 个、互不相邻，彩格始终物理连通
- 后期叠加回色、绕石、传色与换区铺垫；第 19 关包含全部五种思路，五步收束
- 成对传色点在两端同色时增加一条连接，两端区域之后共同染色；提示与撤销遵守相同规则
- 提示使用区域邻接图精确搜索，允许任意区域、任意合法颜色，不限制玩家的解法
- 四向分层扩散；同一传播层共用音阶，按总层数映射完整 24 级音域；五种动效每连续 5 关切换一次，25 关后循环
- 夜泉琉璃界面：细金边画板、矿物颜料纹理、圆形颜料盘、底部线性图标工具栏与 20 关目录；五章使用独立夜景背景
- 本关完成音效、底部彩带喷射和华丽通关弹框
- 撤销、重开、动态提示、静音与关卡推进
- 与小游戏共享代码的浏览器预览页

## 项目结构

```text
game.js                 共享游戏页面和交互
src/                    玩法、关卡、特效与平台抽象
assets/                 双平台共用资源
platforms/wechat/       微信平台配置模板
platforms/douyin/       抖音平台配置模板
platforms/*/ads.json    各平台广告位配置（未配置时不显示广告入口）
tools/build.js          平台构建脚本
src/night-ui.js         深色画板布局、材质和工具栏
assets/art/             五章夜景与四色颜料纹理
dist/                   构建生成，不纳入源码管理
```

源码根目录不是可直接导入平台 IDE 的小游戏工程。平台全局对象和平台配置只会出现在 `dist` 构建产物中。

## 构建与分发

生成两个平台：

```bash
npm run build
```

只生成单个平台：

```bash
npm run build:wechat
npm run build:douyin
```

构建结果：

- `dist/wechat`：导入微信开发者工具，项目类型选择“小游戏”。调试可使用模板中的 `touristappid`，真机与发布前换成实际 AppID。
- `dist/douyin`：导入抖音开发者工具，在工具中选择或填写实际小游戏 AppID。

不要直接修改 `dist`；所有功能改动应写入共享源码或 `platforms` 配置模板，再重新构建。

## 浏览器预览

在本目录运行：

```bash
python3 -m http.server 4173
```

访问 `http://127.0.0.1:4173/preview.html`。浏览器预览使用同一个平台适配接口。默认从第 0 关开始，初染完成后进入第 1 关「相映」。跳关参数现在为 `?level=0` 到 `?level=19`；传色入门是 `?level=12`，最终组合关是 `?level=19`。旧五关体验包的编号已经重新编排，不再保留旧编号语义。

该参数仅用于浏览器开发预览，微信和抖音构建从第 0 关开始；三个平台均可通过顶部关卡条自由选关。拖动不会切关，轻点才切换；切换会重置该关棋盘。

当前设计、难度指标与剧透答案见 `docs/campaign-20.md`，种子和解题证据见 `docs/campaign-evidence.json`。原三关仍保存在 `src/level.js` 的 `legacyLevels`；`docs/challenge-pack.md`、`docs/challenge-qa.md`、`docs/level-02-design.md` 是历史原型记录。

离线候选出题工具（只输出 JSON，不写入题库、不在手机上运行）：

```bash
node tools/generate-campaign.js
node tools/generate-campaign.js 19
```

工具用固定种子搜索、精确求解和机制消融筛选候选，按 JSON Lines 输出。支持五种思路及组合；运行时间取决于筛选条件，不保证任意参数都能找到关卡。手机端只读取已经选定的固定题面。

## 验证

深色概念图还原范围、资源来源及验证边界见 `docs/art/night-glass-implementation.md`。当前 20 关的默认动效是 0—4 墨滴、5—9 柔纸、10—14 涟漪、15—19 湿笔；色露绽放保留并分配给后续 20—24 关。预览页右上角折叠的 development-only 面板可试全部五种，切换会重开当前关。

```bash
npm test
```

测试覆盖原三关回归、二十关最短解与动态提示、四色与连通性、机制必要性、种子复现、旋转镜像换色去重、1024 个小棋盘独立 BFS 对照、二十关在三种尺寸下的模拟绘制/输入、80 关列表扩展、通关衔接、音效与双平台构建。模拟绘制不等于真机视觉验收。构建保留开发者工具维护的 `project.private.config.json`。

构建会保留输出目录中由开发者工具维护的 `project.private.config.json`，避免丢失已选择的调试基础库版本。

音效由 `tools/generate-sfx.js` 本地合成，不依赖第三方音频素材。当前版本已预留微信/抖音激励视频能力：失败后可完整观看一次广告续画 2 步，每次获取提示也必须先完整观看广告；两个入口复用同一激励视频实例。只有在对应 `platforms/*/ads.json` 配置真实广告位 ID 后才显示续画入口，未配置时平台版不发放提示。浏览器预览不连接广告平台，仅保留 development-only 的免费提示旁路，供关卡设计与求解器验证。登录、联网、排行或支付尚未接入。
